# Implementation Phases

## Phase 1: User-centered pilot

- Establish site and navigation
- Publish one cohort→assessment→measure→variable/scoring pathway
- Publish one supported-application task guide
- Validate with scientists, staff, and administrators

## Phase 2: Expand coverage

- Add more cohorts and assessment timelines
- Integrate approved notebooks and summaries
- Expand measure/domain pages
- Add additional application guides

## Phase 3: Sustain and improve

- Establish routine review ownership
- Use search and support signals to identify gaps
- Add structured metadata/automation where useful
