# Stewardship and Access

## Stewardship model

- Data Management coordinates platform structure, search, and publishing standards.
- Subject-matter experts review scientific and interpretation-sensitive content.
- Application maintainers update user instructions as workflows change.

## Page-level quality markers

Where practical, each page should identify:

- Authoritative source(s)
- Review status
- Last meaningful update

## Access controls

Publishing in the hub does not override existing access restrictions.
