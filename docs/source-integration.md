# Source Integration

The hub is centralized for users without requiring all source material to move into one repository.

For local cross-repository work, prefer
[`mctfr-app-stack`](https://github.com/umn-cla-mctfr/mctfr-app-stack). This documentation
repository is `repos/docs-mctfr`, and the sources below are sibling checkouts under
`repos/`. Each source remains independently owned and can also be cloned standalone.

## Priority source repositories

- [umn-cla-mctfr/mctfr_dbs](https://github.com/umn-cla-mctfr/mctfr_dbs)
- [umn-cla-mctfr/study_assistant](https://github.com/umn-cla-mctfr/study_assistant)
- [umn-cla-mctfr/lynx-resources](https://github.com/umn-cla-mctfr/lynx-resources)
- [umn-cla-mctfr/mctfr](https://github.com/umn-cla-mctfr/mctfr)
- [umn-cla-mctfr/mctfr.wiki](https://github.com/umn-cla-mctfr/mctfr/wiki)

## Integration approach

- Link to approved source documents and code examples where they are maintained.
- Publish reviewed summaries in this hub to improve discoverability.
- Expand coverage incrementally as documentation is validated.
- Preserve source provenance and update history for each published page.
