# IS.MCTFR and LYNX Pilot Guide

This pilot guide demonstrates role-oriented task documentation for a supported application.

## Intended users

- Researchers requesting or locating data extracts
- Staff supporting data workflows

## Pilot task flow

1. Determine cohort/assessment context from research-data documentation.
2. Locate the relevant data resource in IS.MCTFR/LYNX.
3. Follow request/extract workflow instructions.
4. Confirm variable/scoring context before analysis.

## Guidance structure

- Getting started and access prerequisites
- Common tasks (find data, request/export, verify context)
- Definitions of key statuses and terms
- Troubleshooting and support path

> This pilot page is intentionally task-first and can link to deeper technical references as needed.
