# MCTFR Documentation Hub

Welcome to the central documentation hub for MCTFR research data and supported applications.

## Purpose

This site provides one searchable starting point for:

1. Understanding and using MCTFR research data.
2. Using MCTFR-supported applications.

It is organized around user questions rather than repository ownership or storage location.

## Requested decision

Approve development of `docs.mctfr.umn.edu`, beginning with a focused pilot that uses existing:

- Research-data documentation (cohort → assessment → measure → variable/scoring → source references)
- User instructions for one supported application (IS.MCTFR/LYNX pilot)

## Start here

- **Research Data**: cohort context, timelines, assessments, measures, variables/scoring, and source provenance.
- **Supported Applications**: task-based guidance for application users.
- **Source Integration**: links to documentation and code resources maintained in related repositories.
