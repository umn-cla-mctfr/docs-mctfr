# Variables and Scoring

This section is the searchable layer for variable-level use.

## Variable documentation standards

For each variable or score, document:

- Definition and interpretation notes
- Value labels and coding conventions
- Missing-value rules
- Derivation/scoring logic and references
- Assessment and cohort applicability
- Known comparability constraints

## Pilot implementation approach

During pilot, variable pages may initially link to approved source documents and metadata tables while standardized summaries are incrementally published.
